Prank Agent // Deploy

Builds a one-line installer for the owner-gated prank bot. Nothing about your bot is stored on this server except an optional one-time code, which is deleted the moment a PC redeems it.

Keep the command private. It carries either your bot token (baked mode) or a single-use code that unlocks it (one-time mode). Run it only on your own PCs, or on PCs whose owner is in on the prank. The agent is owner-gated (only OWNER_ID can trigger anything), the action list is fixed (space / enter / arrows / esc / beep / rickroll / popup), it shows up in Task Scheduler as PrankAgent, and one command removes it.

    How it installs: the command downloads , resolves the .env (one-time code or baked), writes the Python agent to
    %USERPROFILE%\prank-agent, creates a venv, installs three packages, registers the PrankAgent logon task and starts it hidden with
    pythonw. A log lands in install.log. In Discord, run /panel.
    
The one-time code deletes the server-side copy of the .env. The installed PC keeps its own local .env, because the bot reads it on every launch — uninstall removes that too.
